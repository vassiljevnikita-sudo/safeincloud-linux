The application uses all 7,776 words, selecting each independently with OS
randomness. The default memorable password contains six words separated by
hyphens. This is a local passphrase implementation, not a reproduction of the
proprietary SafeInCloud memorable-password algorithm. No network access is
needed to generate a password.
